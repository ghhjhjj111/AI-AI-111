# AI创作小程序源码，文生图，图生图，可对接任何图像AI模型

源码获取：ym7k.com/19846/

## 核心功能模块

### 1. AI 绘图能力（前端）

- ✅ **文生图**：输入正向提示词、反向提示词，设置尺寸、步数、CFG、采样器、生成数量
- ✅ **图生图**：上传参考图，设置重绘幅度，基于原图二次生成、扩图、换背景、风格迁移
- 支持垫图、蒙版局部重绘（高级版）
- 风格预设：写实、二次元、国风、油画、3D、卡通、logo、海报等模板
- 历史作品、我的收藏、作品相册，可下载图片、分享海报
- 作品广场：公开展示用户生成作品，点赞、评论

### 2. 模型调度（系统最大亮点）

- **多模型自由接入**：Stable Diffusion、Midjourney 接口、DALL・E、通义万相、即梦、Kling、本地 SD 服务端等，只要支持标准 http 接口都可以接入
- 后台添加多个模型通道，配置接口地址、密钥、权重
- 模型分组：免费模型、付费模型、高速模型、高清模型
- 负载切换、通道故障自动切换，防止单一接口崩了无法使用
- 可单独给每个模型配置单价、消耗算力点数

### 3. 用户算力、付费变现体系

- 点数机制：生成图片消耗算力点数，不同模型消耗点数不同
- 充值套餐：充值购买点数、会员包月不限次数（限指定模型）
- 卡密兑换：批量生成卡密，用于赠送、线下售卖
- 分销推广：邀请好友注册充值，拿分销佣金
- 新人福利：注册赠送免费点数、每日签到领点数

### 4. 提示词管理

- 提示词广场，用户可收藏别人的优质提示词
- 后台维护提示词模板库、负面词快捷库
- 提示词翻译（中英互译，适配海外模型）

### 5. 后台管理（FastAdmin）RBAC 权限

- 模型通道管理：新增、编辑、启停、测试接口、密钥配置
- 订单管理、充值记录、点数流水、财务对账
- 用户管理、作品审核、敏感词过滤（防止违规绘图）
- 作品管理：下架违规图、设置是否允许公开到广场
- 数据看板：生成次数、消耗点数、充值金额、热门模型、图表统计
- 短信、微信订阅消息、OSS 存储图片

### 6. 其他配套

- 广告位、首页装修，自定义首页组件
- 客服反馈、帮助文档（提示词教程）
- 图片水印开关，可自定义平台水印

## 🖥️ 部署环境

- PHP7.4，MySQL5.7/8.0，Nginx
- HBuilderX 打开 UniApp 源码，编译微信小程序 + H5
- 依赖：对象存储（保存生成图片）、短信、微信支付
- 额外：需要自备 AI 绘图接口（本地 SD 或者第三方 API）
